# 轻量数据库

新建菜单选择“数据库页面”。直接子页面就是记录，每条记录可以打开编辑正文；支持所有已启用笔记格式。状态（未开始、进行中、已完成）、最多20个标签、可选日期属于页面公共 properties，移动、备份和恢复都保留。

表格和看板展示同一批页面。看板拖动或状态菜单更新状态；“编辑属性”修改标题、状态、标签、日期。“新增记录”不会离开数据库。视图选择随笔记保存，查询、状态/标签/日期筛选和排序仅保存在当前编辑器会话。筛选结果为空时可清除筛选。属性编辑弹窗保存失败会保留输入，存在未保存修改时阻止插件停用/重载；取消显式放弃编辑。

Agent：notebook_create({type:'database'}) 创建数据库；notebook_database_read 读取记录和数值 revision；notebook_database_write 新建/更新；notebook_open 打开记录正文。状态更新遵循 notes 的 revision 检查，冲突不会覆盖其他窗口。

这是固定三个属性的第一版，尚无自定义列、公式、数据库关联、汇总、日历、多视图命名和嵌入其他页面。父页面关系决定成员资格，因此删除数据库会将记录提升到上级，恢复数据库不会擅自重新移动这些记录。
