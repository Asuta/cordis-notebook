# 历史与回收站

通过“更多笔记操作 → 历史与回收站”预览和恢复。保存、Agent 修改、恢复以及删除提升子页都会记录覆盖前的持久化版本。每页最近 50 条，全部历史最多 32 MiB，按时间淘汰旧版本；回收站不自动清理。

删除保留原 ID，直接子页上移一级；恢复不会重新收集已移动的子页。历史父关系缺失或形成循环时恢复到顶层。格式插件停用时不能恢复，原记录保留。永久删除需要二次点击，连同该页历史一起清除。附件暂不物理删除，以免其他页或历史仍引用。

笔记、历史、回收站使用同一份原子快照，磁盘写入失败三者都不变。旧数组文件自动读取，第一次成功修改升级为 version:1 的 cordis-notebook-store。JSON 内容备份仅导出当前有效笔记，历史和回收站仍留在本机存储文件中。

Agent：notebook_history 读取版本/回收站；notebook_restore 恢复。恢复历史必须携带最新数值 revision，过期恢复拒绝，恢复前版本仍保留。
