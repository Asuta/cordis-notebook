# 灵感画布

第三个独立应用：在无限画布上摆放文字、图片、视频与生成卡片，通过连线和卡片内参考组织输入，点击生成或让现有工作台 Agent 帮忙操作。

## 插件结构

应用已拆成画布基础、画布界面、基础卡片、图片与视频生成、Pixel、WaveSpeed、Agent 操作七个插件。卡片类型、视图、生成服务和扩展操作通过注册接口接入。停用某个生成服务后仍可编辑画板；关闭 Agent 插件不影响手动操作；缺少卡片插件时保留内容并显示占位提示。

接口、依赖、数据兼容及扩展示例见 [灵感画布插件设计](../../docs/灵感画布插件设计.md)。

## 运行

在项目根目录运行 `pnpm install`，再 `pnpm workbench`，通过「切换应用」选择「灵感画布」。已有工作台需要重启以加载新的图片工具返回协议。正式模式先 `pnpm build` 再 `pnpm workbench:runtime`。

- 空白处拖动平移，滚轮缩放；空格/中键拖动也可平移。
- 点击卡片底板、正文或图片拖动；按钮、链接、输入框、下拉框、视频控件和滚动条保留自身操作。Shift/Ctrl 点击多选，Shift 拖动框选。
- 从文字、图片或视频的连接圆点拖到生成卡片输入圆点，也可依次点击两个圆点。
- 点击连线或输入列表的 × 断开，↑ 调整输入顺序。
- 图片支持 PNG/JPEG/WebP 上传、拖入、粘贴；双击卡片缩略图即可在独立预览中缩放、拖动和下载原图，也可使用卡片底部「预览」。单张上传上限 20 MB。
- 左侧素材库单击放大预览；按住拖到画布时，在落点创建对应图片或视频卡片。
- 视频支持 MP4/WebM 上传、拖入、素材库复用与下载，单个上限 200 MB；结果卡片可直接播放和拖动进度。
- 生成卡片可直接上传或从素材库选择参考，与连线图片、视频一起排序；首尾帧等输入位置在对应参考项中分配。
- 操作自动保存；Ctrl+Z / Ctrl+Shift+Z 撤销和重做本页编辑。重新加载后清空撤销栈，但画板、素材和生成记录保留。
- 撤销/重做会检查相关内容是否已被修改，冲突时保留现状并提示；撤销断线或删除会恢复原输入顺序。
- 画板名称与卡片文字一样自动保存并保留未保存草稿；其他页面同时修改名称时不会直接覆盖。
- 各次生成保存独立结果；没有改动即自动生图或连线即运行的行为。
- 每次提交立即在右侧预留独立结果框和来源连线，显示排队或生成动画，完成后原位显示图片或视频。生成过程中可继续点击生成，各次任务冻结自己的输入；当前全局同时执行 2 项，最多保留 20 个未完成任务，其余排队。任务框支持单独暂停、恢复查询，失败不会影响其他任务；刷新后保留位置和状态。

## 画布交互第一轮

- 顶栏只保留画板名称、保存状态及载入最新；新建文字、图片、生成卡片和撤销/重做位于底部。右下角提供缩放比例、适应全部、聚焦所选和返回视图。
- 选中卡片时，在选区附近显示独立浮栏：文字卡片可进入编辑，图片可预览，生成卡片可编辑提示词；多选时切换为水平/垂直排列。浮栏、底部工具不随画布缩放，并在画布边界内翻转、约束；窄窗口可横向滚动工具。
- 正文输入与卡片选择分开：单击文字输入框继续输入，单击图片/卡片空白选择单张；按 Shift/Ctrl 点击追加或移除选择。已多选时从标题拖动整组，保持相对位置；标题单击不写布局。输入框中 Esc 退出到卡片选择，再次 Esc 清空选择，中文组词期间不截获。
- Shift 拖动空白显示框选区域，按卡片实际高度计算交集；Ctrl/Command+Shift 框选保留已有选择。空白普通拖动平移，按空格或中键可在卡片上临时平移。Esc、指针取消、窗口失焦撤回本次拖动；中键平移不启动连接圆点，拖动过程中暂停滚轮缩放。
- 排列使用实际显示尺寸和 40 个文档单位的间距，以现有左上边界为起点，不修改提示词、图片素材或连线。单次最多排列 100 张卡片，一次排列对应一次撤销；选中后点击「创建副本」或 Ctrl/Command+D 复制整组，保留选区内部连线；生成卡片来自选区外的文字、图片和视频输入转为独立内容，保留顺序和字段绑定，不自动生成。副本共享素材，获得新卡片及连线标识。
- 聚焦/适应按照实际卡片尺寸预留上下工具空间；返回视图恢复定位前的缩放与平移，各画板独立。导航不进入卡片撤销历史；刷新后清空返回点。缩放仍受 15%–300% 限制，自动聚焦最多放大到 125%，跨度极大的画板可能无法一次完整显示。

本轮保持现有卡片和输入连线协议，分组、网格吸附及 Agent 引用展示留待后续轮次。

## WaveSpeed 图片与视频

在侧栏「⚙ WaveSpeed」填写 API Key，默认接口为 `https://api.wavespeed.ai`。Key 仅保存在本机 `data/apps/studio/plugin-data/image-provider-wavespeed/wavespeed-private.json`，界面不回显，留空保存会保留原 Key。

新建「✦ 生成卡片」默认选择 WaveSpeed，再打开模型选择器。旧卡片保持原服务，复制和收藏恢复保持原配置。目录从服务端 GET /api/v3/models 获取，覆盖返回目录中的图片、视频输出模型，支持搜索、输出类型及任务类型筛选、分页与手动刷新。搜索忽略大小写、常见分隔符和版本号前的 v，支持多词匹配，例如 Seedream 5、seedream5。模型可用星标收藏，并通过「我的收藏」筛选，收藏筛选在分页之前执行。默认缓存 15 分钟，按账户隔离；未提供可调用参数定义的模型仍显示原因。没有内置的固定模型白名单。

选定模型后按其 schema 展示参数、默认值、必填项、枚举和范围；对象或复杂结构可用 JSON 编辑。每个模型单独保存参数，切换后可恢复。生成前还会在服务端校验完整请求，错误参数和不能分配的参考不会提交。

参数标题右侧可「收起」，移至卡片正文最下方的「已收起参数」区域，显示名称和当前值；展开后回原位置。收起不改变参数值和提交内容，状态按卡片、模型保存。卡片底部手柄可上下拖拽调整高度，范围 360–20000 个画布单位，也支持聚焦手柄后按上下键；自定义高度允许超过窗口，画布导航可用于查看长卡片。

「提示词」旁的「历史 / 收藏」打开两个页签。历史只来自发起过的生成任务，相同提示词去重，按最近使用排序，显示最近 300 条；编辑但未生成的内容不进入历史。收藏支持名称、正文编辑、回填和删除，修改收藏不改变旧卡片或历史。

侧栏「⚙ 应用设置」的大模型区块可保存多个 OpenAI Responses 兼容配置，并指定一个全局默认模型；接口地址支持填写端口。API Key 仅写入当前应用数据目录的 `llm-private.json`，配置读取接口只返回是否已填写。提示词下方可配置多个优化按钮，每个按钮保存一条独立指令；按钮统一调用默认模型，先展示原文和优化结果，点击「使用优化结果」后才替换主提示词输入框。固定尾缀不参与优化，优化期间手工改动主提示词也会阻止覆盖。

每个大模型可以单独设置推理模式：跟随服务默认、关闭推理，或开启推理并选择 Minimal / Low / Medium / High / XHigh / Max 强度。旧配置默认跟随服务；关闭时发送 `reasoning.effort: none`，开启时发送所选强度，连接测试与提示词优化使用同一配置。支持的模式和强度取决于模型及兼容接口，不支持时会显示服务返回的错误，可切回「跟随服务默认」。

标题栏 ☆ 或选中浮栏「收藏卡片」保存完整生成配置。侧栏「生成卡片收藏」或底部「卡片收藏」打开收藏库，可以查看提示词、参数和引用数量，点击添加或拖入画布。收藏会将所有连线输入保存为独立快照，跨画板恢复时保留顺序、模型参数、首尾帧绑定、收起状态和高度，不携带原任务身份、不自动生成。模型、提示词和卡片收藏在当前 Studio 内共用，保存在 canvas/studio.json 的 generation-library 扩展记录中，刷新和重启后保留。

「参考素材」先点「＋ 新建参考槽位」创建空槽位，再点击空槽位左侧的 ＋ 打开素材选择：可直接选素材库中的内容，也可在弹窗内上传本机图片或视频。也可以连接画布上的图片、视频卡片。卡片参考与连线参考共用一个有序列表，拖动行首手柄可平滑调整顺序，聚焦手柄后也可使用上下方向键排序；单击图片参考右侧的「快速编辑」可打开编辑器，在原图上画出示意线条，保存后新增一张独立参考图并保留原图；单击已填素材缩略图可在独立界面放大浏览。空槽位保留在列表中但不参与生成。单一媒体字段可自动分配；首帧、尾帧、蒙版等多个位置须明确选择。每份参考必须使用，超限、不支持的素材或遗漏必填输入会明确报错。上传使用 WaveSpeed 返回的 ticket，原签名地址、文件字节及 ticket headers 保持原样；上传和结果下载不会附带 API Bearer。

生成记录保存模型、实际参数、参考顺序、字段绑定与远端任务 ID。多个图片或视频输出各自保存并创建结果卡片。页面刷新继续读取本地任务；应用或服务重启后，有远端 ID 的未结束任务只恢复查询，不重新提交。点击「暂停查询」后可手动恢复；若 POST 结果未知且没有 ID，会显示「提交结果待确认」，需先核对 WaveSpeed 任务记录。核对后可结束本地跟踪，再决定是否重新生成。暂停或结束跟踪不保证停止远端生成或退费，恢复查询要求使用原账户配置。

Agent 保留原有 10 个工具，通过 `studio_read.actions` 和 `studio_action` 发现并调用模型搜索、模型定义、生成、恢复查询和结束跟踪；图片与视频都可通过已有导入工具加入。具体字段及操作步骤见 `agent.md`。

## AI Pixel

首次启动从进程环境或本机 `.codex/config.toml` 的 `[skills.ai-pixel-image2.env]` 导入现有接口、Key 和模型，随后独立保存到 `data/apps/studio/plugin-data/image-provider-pixel/pixel-private.json`；升级时优先一次性导入旧 `canvas/pixel-private.json`，保留旧文件并以新配置为准。默认 `https://ai-pixel.online`、`gpt-image-2`。不运行技能脚本，不在前端或仓库保存 Key；设置界面只显示是否已配置，留空保存保留原 Key。

纯文本请求为 `/v1/images/generations` JSON；有参考图时为 `/v1/images/edits` multipart `image[]`。Node 请求使用环境代理。生成超时 10 分钟，最多同时执行 2 项用户/Agent 明确启动的任务，最多保留 20 项待完成任务。比例与目标分辨率转换为按 64 像素对齐的 size；最终实际尺寸以返回图片为准。

较大的参考图仅在上传时生成优化副本，使参考图总量不超过约 1.875 MiB，预留 multipart 和提示词空间。优先保持细节，不透明图片使用 JPEG，透明图片保留 PNG 透明通道；必要时缩小参考副本。画布素材原图、下载原图和目标生成分辨率不变。这是当前上传链路的兼容措施，不代表图片服务公布的大小限制。

生成时冻结提示词、参数、参考图和模型。Pixel 在关闭/切换应用、停用生成服务或对应提供者后中断待完成任务，重新打开不自动重试。仅刷新页面不会自动重发请求；已接收的服务端任务可继续完成。断开本地请求不保证撤销服务端生成或退费。

数据保存在 `data/apps/studio/plugin-data/canvas/`（独立验收实例使用自己的目录）：`studio.json` 存画板、任务与素材索引，`images/` 存原图及缩略图，`videos/` 存原视频。旧图片资产缺少 kind 时继续按图片处理。删除卡片不删除素材，可从素材库重新加入。画板最多 50 个，每板最多 500 张卡片、1500 条连线；首版不提供永久清理素材操作。

## 验证

`pnpm test:plugin --app studio --plugin image-generation`：类型、构建与插件业务测试，默认不请求真实 Pixel。

`pnpm test:plugin --app studio --plugin image-provider-wavespeed`：目录、参数、统一参考、HTTP 上传与远端任务恢复。`test/studio-wavespeed-runtime.test.js` 使用真实本机 HTTP 服务和 MP4/WebM 文件，数据与真实画板隔离；不调用付费 API。浏览器验收运行 `$env:CORDIS_BROWSER_TEST='1'; node --test test/studio-wavespeed-browser.test.js`。

`pnpm exec node --test test/studio-client.test.js test/app-tool-result.test.js`：用户/Agent 共用交互与图片工具结果协议。图片、视频协议和真实 UI 分别由本机模拟服务及 Chromium 验证；这些测试不代表所有真实 WaveSpeed 模型都已付费实测。
