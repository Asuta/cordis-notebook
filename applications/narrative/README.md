# 叙事引擎

以「七日会客厅」为起点的网页场景搭建应用。作者组合对象、布局、角色和事件连接；玩家与角色自由交谈、推进天数，并保存独立进度。应用 ID 为 narrative。

## 开始使用

仓库根目录运行 pnpm install --frozen-lockfile、pnpm workbench，在应用选择器打开「叙事引擎」。独立开发可设置 APP=narrative 后运行 pnpm dev；构建使用 pnpm build narrative。

新建作品提供七日会客厅、视觉小说《末班车之前》和调查小游戏《雨站失物》。会客厅包含两个独立角色会话、共同经历计数和天数推进。AI 连接在「AI 对话」面板配置；离线体验在「场景搭建」中将角色会话对象的内容来源设为「预写文本」。模型失败会显示错误，不会自动伪装成预写回复。

《末班车之前》是一部单女主、预写对白的短篇视觉小说：雨后的站台、即将关闭的观测站，以及末班车到来前的一次约定。无需模型配置，通过不同选择走向两个结局。作品库选择同名模板创建；点击试玩，点击画面或在画面获得焦点后按空格推进，打字期间再次点击显示整句。画面提供自动播放、回看、存读档、音乐和全屏；自动播放在选择和结局处停止，打开设置时暂停推进。音乐需主动点击开启。

在层级中选中「剧情流程」，从右侧「编辑这份剧情」进入专用编辑器；资源库的「剧情资源」和「更多 → 剧情与对白」也可进入。每份剧情资源保存章节、逐句对白、背景、角色出入场、表情、后续章节、变量和分支条件。可以新建或切换资源，选择对应流程实例后从指定章节试读。同一份剧本可以被多份流程实例引用，游标、变量和历史分别保存。选中人物显示或角色会话对象可直接编辑人物资料与表情。

《雨站失物》复用背景、对白框、选项列表、按钮和计数器。调查长椅、车票、值班室，三个地点各计数一次，再查看推理结论。它没有剧情资源、没有剧情流程实例，也不调用 AI，用来演示同一组显示与交互插件如何组成另一种玩法。

## 场景编辑

编辑器使用四区域布局：左侧只放当前场景的对象层级，中间是编辑与试玩共用的游戏画面，右侧显示所选对象或资源的属性，底部是统一资源库。作品、角色档案、AI 对话、声音、存档和插件管理从顶部进入，不再嵌套一套插件导航与预览。

资源库可搜索图片、音频、对象类型、预制体、人物资料、剧情资源和组合，支持导入不超过 5 MB 的 PNG/JPEG/WebP 与 MP3/WAV/OGG。单击查看属性和引用位置，再点击“放入场景”；也可双击或拖入场景/层级容器。人物资料放入后会创建独立会话与聊天窗口，剧情资源放入后创建绑定它的流程对象；音频可预听、设为背景音乐。选中对象时可通过引用跳转到关联对象。

「组合」提供对白演出组合和剧情播放组合。前者仅组合背景、立绘、对白与选项，后者附带流程、播放控制及事件连接。放入场景后保存为作品中的预制体版本，可编辑实例覆盖值、展开为普通对象，也可撤销；剧情播放组合运行前需要绑定有效剧情资源。

画面中拖动对象或左上角手柄，纵向、横向、滚动和网格布局只调整同级顺序；叠层/锚点容器吸附四角或中心，不生成额外像素坐标。右下角手柄调整宽高，单次手势对应一次撤销操作；Esc 取消。窄屏画面中的尺寸和锚点变化写入 compact 覆盖。跨容器移动可拖到左侧容器，或使用父对象属性。预制体子对象可调整覆盖值，需要改变结构时先展开为普通对象。

顶部支持撤销/重做、保存、自动保存状态，以及横屏和竖屏固定比例预览。小于 800px 的编辑界面通过“画面/层级/属性/资源”切换区域，保持主要操作可用。基础对象包括容器、文字、图片、按钮、数值状态、数值显示、角色会话、聊天窗口、场景切换按钮，以及下列可独立组合的剧情与显示对象。

对象是数据实例，共享插件提供的类型实现。预制体保存可复用组合及显式版本引用；每份实例具有独立状态与覆盖值。父子关系管理生命周期，引用使用稳定 ID，事件调用对象公开方法。纯逻辑对象不占画面，禁止直接修改其他对象状态。

布局使用网页 Flex/Grid、锚点、叠层与滚动区，支持窄屏覆盖。编辑支持撤销、重做、自动保存、草稿恢复与版本冲突保护；直接操作和 Agent 使用相同场景命令及版本校验。试玩时配置只读，可从层级选择对象查看实时状态；停止后回到之前的编辑场景和选中对象。玩家变化进入存档，不写回作者配置。存档包含场景状态和独立聊天记录。

## 应用插件

| 插件 | 职责 |
| --- | --- |
| project | 作品、剧情资源、三类模板、组合预设、保存和数据接口 |
| shell | 顶部工具栏、作品库、设置面板、对象专用编辑入口注册与编辑器宿主 |
| scene-runtime | 对象类型、实例、方法、事件、调用记录、快照和 Agent 工具 |
| scene-ui | 基础对象及 DOM/CSS 渲染 |
| scene-editor | 四区域编辑器、统一资源库、布局直接操作、属性、事件连接与调试面板 |
| characters | 人物资料、立绘、表情与图片素材 |
| ai-dialogue | 模型连接、世界设定、角色回复和私有密钥 |
| sound | 音频素材、预听、背景音乐和音量 |
| saves | 三个手动存档位及自动进度 |
| story-flow | 引用剧情资源的独立流程实例、分支变量与内容事件 |
| story-editor | 多剧情资源、章节、对白、变量、分支和定向试读的编辑面板 |
| background-view | 独立背景显示 |
| character-view | 独立角色立绘、表情与位置 |
| dialogue-view | 对白框、逐字显示与继续事件 |
| choice-list | 选项显示与选择事件 |
| history-view | 历史记录与回看窗口 |
| auto-advance | 阅读等待计时与自动推进事件 |
| playback-controls | 章节提示、存读档入口、重开、音乐与全屏 |

《末班车之前》是对象和事件连接组成的作品数据。上述显示插件不依赖 story-flow，也不互相要求安装：例如对白框可以用于调查提示，选项可以连接数值状态对象。各插件只声明所需的公共宿主服务；作品中的引用与连接按目标公开能力校验。移除对象后需同步调整相关连接。

旧 visual-novel 插件已拆除，旧 story-player 对象在读取作品时自动迁移为这组对象与连接，保持原容器 ID；新格式在下次保存时写入。旧剧情、规则、Mesh 动态立绘及 Live2D 插件仍不恢复。已有作品文件不会删除；旧格式测试样本仅用于兼容性验证。

旧作品的全局 nodes/variables 读取时迁移到默认剧情资源，旧全局进度在能唯一识别流程对象时迁移到该实例。会客厅等不使用剧情的作品保留空 stories 列表。损坏或无法确定归属的存档会拒绝加载，保留当前进度。

## 模型、数据与 Agent

支持 Chat Completions 与 Responses 协议，模型由作者指定。此版回复完成后整段显示，支持取消；不含 TTS、自动生图或多人发言调度。AI 生成角色文字，数值变化通过作者设置的事件连接触发。

默认作品数据位于 data/apps/narrative/plugin-data/project/；模型密钥位于 ai-dialogue/settings-private.json，实际根目录取决于 DATA_DIR。密钥不随作品导出。存档保存在当前浏览器的插件专属空间。

导出 .narrative.json 保存场景、人物、预制体、事件和上传素材；内置素材由相同版本应用提供。含旧动态立绘资源的作品不能在精简版完整导出。

工作台 Agent 使用 narrative_read/edit 编辑完整作品，使用 narrative_scene_read/edit/call 读取类型、编辑场景或在试玩中调用公开方法。narrative_scene_trace 只读获取近期调用，帮助定位事件连接问题。新增对象类型和编辑器功能通过修改所属插件代码实现。

试玩后打开「更多 → 设置… → 事件调试」，可查看最近 200 条方法调用：来源事件、目标方法、参数摘要、结果、错误及耗时。支持搜索、只看失败、暂停记录和清空；记录只保存在当前页面，不写入作品或存档。

接口见 CONTRACT.md。预制体暂不支持递归嵌套、自动版本升级；不含物理引擎、多人联机、插件市场和在线发布平台。

## 验证

pnpm typecheck、pnpm build narrative；使用 pnpm test:plugin --app narrative 配合 --plugin 参数选择本应用插件。页面另用 Codex 内置浏览器验证场景编辑、试玩、聊天、存档和插件启停。

编辑器支持横屏 16:9 / 竖屏 9:16 固定比例预览，完整画面等比缩放并居中留黑边。顶部操作合并为一行，次要操作在「场景选项」和「更多」中。拖动左、右、下分界线可调整各栏大小，双击复位；鼠标在资源库内按 Ctrl + 滚轮可放大缩小卡片，点击百分比恢复默认。布局偏好在当前浏览器中保存，编辑与试玩均可调整。
