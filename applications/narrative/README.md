# 叙事引擎

以「七日会客厅」为起点的网页场景搭建应用。作者组合对象、布局、角色和事件连接；玩家与角色自由交谈、推进天数，并保存独立进度。应用 ID 为 narrative。

## 开始使用

仓库根目录运行 pnpm install --frozen-lockfile、pnpm workbench，在应用选择器打开「叙事引擎」。独立开发可设置 APP=narrative 后运行 pnpm dev；构建使用 pnpm build narrative。

新建作品仅提供七日会客厅：两个独立角色会话、共同经历计数和天数推进。AI 连接在「AI 对话」面板配置；离线体验在「场景搭建」中将角色会话对象的内容来源设为「预写文本」。模型失败会显示错误，不会自动伪装成预写回复。

## 场景编辑

场景搭建包含对象层级、属性、布局、引用、事件连接、预制体及桌面/390px 竖屏预览。基础对象包括容器、文字、图片、按钮、数值状态、数值显示、角色会话、聊天窗口和场景切换按钮。

对象是数据实例，共享插件提供的类型实现。预制体保存可复用组合及显式版本引用；每份实例具有独立状态与覆盖值。父子关系管理生命周期，引用使用稳定 ID，事件调用对象公开方法。纯逻辑对象不占画面，禁止直接修改其他对象状态。

布局使用网页 Flex/Grid、锚点、叠层与滚动区，支持窄屏覆盖。编辑支持撤销、重做、自动保存、草稿恢复与版本冲突保护。存档包含场景状态和独立聊天记录。

## 保留的九个插件

| 插件 | 职责 |
| --- | --- |
| project | 作品、会客厅模板、保存、草稿和数据接口 |
| shell | 工作室、导航、作品库和预览 |
| scene-runtime | 对象类型、实例、方法、事件、快照和 Agent 工具 |
| scene-ui | 基础对象及 DOM/CSS 渲染 |
| scene-editor | 层级、属性、布局、引用、预制体与行为连接编辑 |
| characters | 人物资料、立绘、表情与图片素材 |
| ai-dialogue | 模型连接、世界设定、角色回复和私有密钥 |
| sound | 音频素材、预听、背景音乐和音量 |
| saves | 三个手动存档位及自动进度 |

已移除旧剧情流程、旧舞台、旧对白、旧规则、Mesh 动态立绘及 Live2D 插件，以及对应模板和编辑入口。已有作品文件不会删除；旧剧情作品的数据结构仍可读取与导出，但依赖已移除插件的玩法不再运行。旧格式测试样本仅用于验证数据校验与持久化，不是可选模板。

## 模型、数据与 Agent

支持 Chat Completions 与 Responses 协议，模型由作者指定。此版回复完成后整段显示，支持取消；不含 TTS、自动生图或多人发言调度。AI 生成角色文字，数值变化通过作者设置的事件连接触发。

默认作品数据位于 data/apps/narrative/plugin-data/project/；模型密钥位于 ai-dialogue/settings-private.json，实际根目录取决于 DATA_DIR。密钥不随作品导出。存档保存在当前浏览器的插件专属空间。

导出 .narrative.json 保存场景、人物、预制体、事件和上传素材；内置素材由相同版本应用提供。含旧动态立绘资源的作品不能在精简版完整导出。

工作台 Agent 使用 narrative_read/edit 编辑完整作品，使用 narrative_scene_read/edit/call 读取类型、编辑场景或在试玩中调用公开方法。新增对象类型和编辑器功能通过修改所属插件代码实现。

接口见 CONTRACT.md。预制体暂不支持递归嵌套、自动版本升级；不含物理引擎、多人联机、插件市场和在线发布平台。

## 验证

pnpm typecheck、pnpm build narrative；使用 pnpm test:plugin --app narrative 配合 --plugin 参数选择本应用插件。页面另用 Codex 内置浏览器验证场景编辑、试玩、聊天、存档和插件启停。
