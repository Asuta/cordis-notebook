# 叙事作品创作

作者通过组合可复用的对象来制作互动作品；玩家运行作品并保存独立进度。

## 术语

**能力插件**：提供对象类型、编辑功能或共享服务的可安装模块。插件不等于场景中的一个实例。

**对象类型**：描述一种对象的配置、只读状态、公开方法和事件。

**对象实例**：作品中的一个有稳定标识的对象，拥有独立配置与运行状态，可以没有可见外观。

**预制体**：可复用的对象组合，包含默认配置、内部引用与行为连接；实例明确引用某个版本。

**界面场景**：对象实例、布局层级和行为连接构成的画面及其逻辑对象集合。

**剧情节点**：故事流程中的一个阶段，与界面场景中的布局节点不同。

**剧情资源**：具名的剧本数据，包含起始节点、章节、对白、分支、初始变量及兼容规则。它不持有玩家进度；作品可以没有剧情资源。

**流程实例**：引用一份剧情资源的逻辑对象，独立保存当前章节、对白位置、变量和历史。多个实例可以复用同一资源而不共享进度。

**组合预设**：应用提供的起始对象组合；放入场景后登记为作品中的预制体版本，可覆盖属性或展开修改，不是新的玩法插件。

**对象专用编辑入口**：插件按对象类型注册的检查器内容，用于就近打开所绑定的剧情、人物等资源编辑器。

**归属关系**：对象由哪个父对象包含并管理生命周期。

**对象引用**：对象对另一对象的稳定标识引用，不改变被引用对象的归属。

**行为连接**：一个对象的事件触发另一个对象的公开方法，可携带经过声明的参数。

**作品配置**：作者保存的场景、预制体、人物与剧情初始定义。

**玩家进度**：特定作品版本下的运行状态，独立于作者配置。

**调用记录**：最近的对象方法执行信息，包含来源事件、目标、参数摘要、结果和耗时，用于作者与 Agent 调试，不进入作品或玩家进度。
