# 画图应用

用于验证同一个宿主可以承载完全不同的应用。两个插件均在本应用自己的 `plugins/` 中；没有笔记插件依赖，也不借用笔记应用的布局、React、主题或存储服务。

- `storage`：提供后端 `drawingStorage` 服务。作品保存在 `data/apps/drawing/plugin-data/storage/drawing.json`，采用串行原子写入与 revision 冲突检查。
- `canvas`：提供 `/api/drawing` 接口与前端画布。支持画笔颜色、粗细、撤销、清空、自动保存与 PNG 导出；设置面板可调整默认粗细。界面和 CSS 随插件启停挂载和清理。

当前是单作品的基础画图示例，使用固定 1200×800 画布，最多 3000 笔、共 30000 个坐标点。笔记和画图中的 `storage` 是各自的插件实例，互不共享数据。

草稿使用 `sdk.storage.local`，再按标签页区分，成功保存后清除。主动切换应用会先完成当前笔画并保存；保存失败会阻止切换。其他页面切换应用时，本页保留未保存草稿并刷新。如果作品已在另一页面更新，会拒绝旧 revision 的保存；可先导出 PNG，再用「载入已保存版本」放弃本页草稿并读取最新作品，暂不做协同合并。

构建本应用：`pnpm build drawing`。打开宿主页面右上角「切换应用」选择「画图」。数据目录与切换协议见 [应用开发与切换指南](../../docs/应用开发与切换指南.md)。
