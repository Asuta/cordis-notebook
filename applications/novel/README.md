# 雨幕故事工坊

作品库的「✦ Miko 官方角色示例」创建《海风里的邀请 · Miko 官方角色》：使用 Mesh Avatar Studio 官方预制 Miko（旗袍），含三个场景、两个结局，演示左右转头、俯仰、歪头、视线、表情、呼吸、口型和发饰物理。游戏使用上游原生 WebGL 渲染器，角色工程及素材都在本地，无需图像服务或 Python 即可试玩。

作品编辑器左栏的「Mesh Avatar Studio」嵌入完整上游角色编辑器，可以调整脸部、眼嘴、头部绑定、表情和物理。点击「保存并用于游戏」同步模型版本，再用「游戏中预览」检查演出；工作台 Agent 也可直接读取、修改、预览、校验和保存同一工程。角色以原生 `.mavatar` 保存，作品包携带可重新编辑的完整工程、分层和表情素材；旧模型版本保留供旧存档播放。

Mesh Avatar Studio 与 `mesh-avatar` 运行时采用 MIT 许可，固定来源见 [PROVENANCE.md](plugins/game/mesh-avatar/PROVENANCE.md)。Miko 角色另有 [素材使用条款](plugins/game/mesh-avatar/vendor/samples/miko-qipao/MIKO_ASSET_TERMS.md)：随游戏或应用分发时保留许可，不作为独立素材包分发；本集成为独立项目，与原作者没有官方关联。该开放格式不导出 Cubism `.moc3`。分层重建另需本地 `uv`、Python 3.10–3.13 及图像依赖，编辑绑定、保存和游戏播放无需这些依赖。

更新上游适配后，先运行 `node applications/novel/plugins/game/scripts/build-mesh-avatar.mjs` 生成嵌入式编辑器和运行时，再执行 `pnpm build novel`。

作品库的「✦ 汐音原创角色示例」创建《月下听潮 · 汐音》。汐音使用新生成的正面垂臂立绘，按新图独立标注头身、五官、发丝与双臂；包含闭眼、半睁眼、笑眼和多种口型。示例逐段展示转头、俯仰、视线、表情、呼吸与丝绦物理，包含两个结局。模型及全尺寸眼嘴素材随作品包往返，也可进入 Mesh Avatar Studio 继续编辑。原图、绑定和分层位于 `plugins/game/assets/avatar/shion/`，重建命令为 `uv run applications/novel/plugins/game/scripts/build-shion.py`。

侧栏「角色工作室」可制作和编辑动态立绘：部件树、排序、显隐与锁定、网格顶点、单参数 / 多参数关键形、参数绑定、变形器层级、遮罩、表情、动作时间轴和头发物理。画布支持部件移动和顶点拖动；「记录当前姿态」将当前网格记为参数关键形。手工编辑与工作台 Agent 共用撤销、重做、草稿缓存和模型版本冲突保护。

「眼嘴素材」可检查或导入独立闭眼与张嘴 PNG。自动制作增加与原图对齐的眼嘴补画阶段，并从中裁出两张闭眼和一张自然张嘴素材，随开合参数切换；旧模型没有这些素材时保留形变兼容。视线使用局部网格形变固定眼角；头发与饰品由物理参数驱动局部网格，发根保持固定。重新自动绑定保留手工关键形、手工层级和锁定部件。

「姿态检查」提供14个固定姿态，冻结待机和物理以检查眼嘴、转头、视线和发梢。可标记通过或记录返修备注；检查记录仅属于当前工作室会话，修改模型后清空。自动诊断定位缺少眼嘴素材、未启用物理和网格翻折，不能判断素材对齐或美术自然度。候选采用前也可切换这些姿态。Agent 使用 `novel_model_check` 访问同一套检查与诊断。新增纹理和眼嘴补画随作品包导出、重映射，导入后仍可编辑。

从单张立绘制作时，在工作室选择原图并启动 AI 制作，依次执行「AI 部件分区 → 脸部补画 → 从原图拆出透明部件 → 自动绑定」。可查看阶段图片、用画笔修正分区、复用分区图和补画、取消或重试任务。完成后先预览候选模型，再采用到作品；原模型不会被候选覆盖。AI 拆层是起稿工具，复杂遮挡和极限姿态仍需手工修整。图像服务默认复用本机 FUN Token Image2 配置，也可在工作室设置；密钥只保存在服务端。

在「角色设定」关联动态模型后，用「动态角色演出」指令设置表情、动作、待机开关和参数覆盖。剧情与编辑预览共用渲染，支持呼吸、眨眼、转头、视线、发丝物理和口型；对白可关联语音素材，以音量驱动口型，无语音时跟随逐字显示。模型演出状态随存档和回退恢复。作品库的「＋ 动态角色示例」创建原创短篇《寄给明天的第七封信》，含两个结局和可继续编辑的完整模型。

模型采用开放 JSON 工程，渲染使用固定版本的 [StandRig](https://github.com/sayaka-aiart/StandRig) Canvas 运行时（Apache-2.0）；上游来源、提交与许可证保留在 `plugins/game/live2d/vendor/standrig/`。此格式面向本应用的制作和游戏演出，不导出 Cubism `.moc3`。模型文档、编辑操作与 Agent 工具见 [agent.md](agent.md)。

演出指令支持背景镜头平移 / 缩放 / 旋转、画面震动、雨 / 雪 / 樱花天气，以及亮度、对比、饱和、黑白、怀旧、模糊和色相滤镜。滤镜提供回忆、梦境、夜景、晨光等预设。效果只影响画面，不移动对白和阅读按钮；天气和滤镜持续到后续指令重置。

侧栏「关键帧动画」提供呼吸、悬浮、推进、摇摆、点头预设，可编辑时间、位移、缩放、旋转、透明度、缓动与循环次数。通过「关键帧动画」指令应用于背景、整个场景或指定角色；同一目标的新动画替换旧动画，空动画停止。角色动画在切场景后清除。演出编排的「播放演出」和动画库的「播放 / 重播」可直接检查效果。

对白属性支持普通对白、全屏独白和电影字幕；可调颜色、字号、对齐、粗体、斜体，并按段设置颜色和注音。逐字显示保留这些样式。镜头、滤镜、天气及动画定义随作品包导入导出；存档和回退恢复画面状态，一次性震动和已恢复的一次性动画不重播。

横屏制作工作区现支持演出指令序列、常驻画面预览、属性面板、立绘拖动、指令排序和变量测试。通过「剧情树」进入连线画布，拖动场景整理位置、点击「从此连线」再选目标建立分支；原有树形浏览保留。手工和 Agent 共用撤销、重做与版本保护。

播放器支持逐字显示、点击补全、自动播放、已读快进、历史回看、隐藏对话框、六个手动存档槽、自动/快捷存档与剧情回退。方向右键/空格推进，方向左键回退，Esc 打开设置。存档绑定作品版本；作品编辑后旧存档会标记为不可用。结局、已读和 global 变量跨周目保留，普通变量随存档恢复。

工作台 Agent 可通过 `novel_play` 启动当前作品的真实试玩、读取状态、推进对白或等待、按 ID 选择可用分支、回退、重开和退出。可从指定场景/指令及测试变量启动；工具与页面共用播放器和存档，状态返回对白、舞台、变量和条件满足的选项。调用参数与示例见 [agent.md](agent.md)。

旧作品和旧作品包自动升级为第二版指令数据。作品库的「＋ 演出示例」创建原短篇的独立演出版本，包含人物入场、移动、转场、等待和程序合成的信标音效，不覆盖已有作品。编辑预览从当前场景初始值重建，可设置测试变量，再从选中指令试玩。

第四个独立应用，第一版由一个 `game` 插件实现。作品库可以创建多部视觉小说；在编辑器里写场景对白、连接分支、安排背景/立绘/音乐，并设置数字、布尔变量和角色好感度。剧情流向页提示断开的选项、无法到达的场景和缺失素材。任何场景都可即时试玩，玩家进度按作品保存在本机浏览器。

首次打开会得到原创短篇《雨停以后，星光来信》：9 个场景、3 个结局；其中两个结局需要对应角色好感度达到 2。两张背景和两张角色立绘使用 FUN Token Image2 生成，立绘经白底抠图后保留透明通道；循环音乐由 `plugins/game/scripts/generate-music.mjs` 合成。美术提示词与处理脚本位于插件目录。

作品数据存于 `data/apps/novel/plugin-data/game/projects/`（可用 `DATA_DIR` 更改根目录）。剧情 JSON、模型 revision 快照与各素材独立保存；写入使用原子快照和 revision 冲突检查。浏览器在自动保存前会备份未保存的剧情与模型草稿。删除作品会一并删除其素材；该操作由用户在作品库中明确确认。每个作品最多 300 个场景、800 个素材、30 个模型；单个素材最多 8 MB，素材总量最多 256 MB，剧情 JSON 最多 1 MB，单个模型工程最多 12 MB；这些限制同时应用于保存和导入。

作品包为单个 `.novel.zip`，包含 `project.json`、`media/` 下的素材和 `models/` 下的可编辑模型。接收者需要运行同一应用，在作品库点击“导入作品包”后试玩或继续编辑；导入创建独立副本，重新映射角色、模型、纹理、语音和生成阶段图片引用，不覆盖已有作品。第一版不生成独立可运行网页，也不托管在线分享链接。

运行：在仓库根目录执行 `pnpm install` 和 `pnpm workbench`，然后通过“切换应用”打开“雨幕故事工坊”。开发时插件源码热更新；正式构建可运行 `pnpm build novel`。针对性验证：`pnpm test:plugin --app novel --plugin game`。工作台 Agent 使用方式见 [agent.md](agent.md)。
