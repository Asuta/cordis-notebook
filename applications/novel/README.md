# 雨幕故事工坊

第四个独立应用，第一版由一个 `game` 插件实现。作品库可以创建多部视觉小说；在编辑器里写场景对白、连接分支、安排背景/立绘/音乐，并设置数字、布尔变量和角色好感度。剧情流向页提示断开的选项、无法到达的场景和缺失素材。任何场景都可即时试玩，玩家进度按作品保存在本机浏览器。

首次打开会得到原创短篇《雨停以后，星光来信》：9 个场景、3 个结局；其中两个结局需要对应角色好感度达到 2。两张背景和两张角色立绘使用 FUN Token Image2 生成，立绘经白底抠图后保留透明通道；循环音乐由 `plugins/game/scripts/generate-music.mjs` 合成。美术提示词与处理脚本位于插件目录。

作品数据存于 `data/apps/novel/plugin-data/game/projects/`。剧情 JSON 与各素材独立保存；写入使用原子快照和 revision 冲突检查。浏览器在自动保存前会备份未保存的剧情草稿。删除作品会一并删除其素材；该操作由用户在作品库中明确确认。每个作品最多 300 个场景、100 个素材，单个素材最多 8 MB，素材总量最多 50 MB，剧情 JSON 最多 1 MB；这些限制同时应用于保存和导入，保证导出的作品可以重新导入。

作品包为单个 `.novel.zip`，包含 `project.json` 和 `media/` 下的素材。接收者需要运行同一应用，在作品库点击“导入作品包”后试玩或继续编辑；导入创建独立副本，不覆盖已有作品。第一版不生成独立可运行网页，也不托管在线分享链接。

运行：在仓库根目录执行 `pnpm install` 和 `pnpm workbench`，然后通过“切换应用”打开“雨幕故事工坊”。开发时插件源码热更新；正式构建可运行 `pnpm build novel`。针对性验证：`pnpm test:plugin --app novel --plugin game`。工作台 Agent 使用方式见 [agent.md](agent.md)。
