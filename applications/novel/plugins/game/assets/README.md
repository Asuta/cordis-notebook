# 示例作品素材

这四张美术图使用本机 FUN Token Image2 技能的 `gpt-image-2.5-sunburst` 模型生成，再由 `../scripts/prepare-images.mjs` 调整尺寸并处理角色白底。两张立绘保留透明通道。背景生成图未完全遵守要求的 16:9 比例，因此裁切为 1280×720。原始输出不参与应用构建。

- `observatory.png`：雨后蓝调时刻的海边观测室，黄铜望远镜、暖色台灯、靛蓝与青绿色、无人、无字。
- `station.png`：夜雨刚停的海边火车站，灯光映在湿站台上，远处海岸与山、无人、无字。
- `lin.png`：24 岁的林汐，棕色长发、米色风衣、藏青裙、手持星图、站姿、白底。
- `yao.png`：26 岁的姚青，短银黑发、海蓝眼睛、观测室技术员外套、手持笔记本、站姿、白底。

`rain-theme.wav` 使用 `../scripts/generate-music.mjs` 程序合成，32 秒循环，不依赖外部音频。运行时只读取构建后的素材副本，并在应用数据目录首次创建示例作品时复制素材。
