# 块页面设计与使用

在笔记列表点击「新建」→「块页面」，即可使用 Notion 风格的流式编辑页面。格式由 `applications/notebook/plugins/format-block` 注册，界面由 `applications/notebook/plugins/block-editor` 提供；两个插件默认启用。它与支持自由坐标的「自由页面」是独立格式，不会转换或覆盖已有笔记。

## 编辑操作

- 在空块输入 `/` 打开块菜单，也可以点工具栏「插入」或块旁的 `+`。菜单提供正文、三级标题、项目/编号列表、待办、折叠、引用、提示块、代码、分割线、表格和图片。
- Enter 新建块，Shift+Enter 块内换行；Tab / Shift+Tab 嵌套或取消嵌套。在表格里 Tab 切换单元格。
- 拖动块旁的 `⠿` 调整顺序或嵌套；Alt+Shift+↑/↓ 移动块，Ctrl/Cmd+Shift+D 复制块。
- 点击待办或折叠标记切换状态；Ctrl/Cmd+Enter 切换当前待办/折叠块。
- 工具栏提供粗体、斜体、下划线、删除线、行内代码、高亮和链接。Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。撤销历史属于当前编辑器实例，刷新或切换笔记后不保留。
- 沿用应用的自动保存、Ctrl/Cmd+S 保存和草稿保护。图片通过 note-assets 上传；JSON 文档引用图片地址，备份时还需保存图片资源。

## 数据与集成

`note.type` 是 `block`。正文原始数据为 `document: { version: 1, blocks: [...] }`，块包含稳定 `id`、`type`、富文本 `body`、`checked`、`collapsed` 和嵌套 `children`。`body` 使用应用的 OutlineDocument；Tiptap JSON 仅用于编辑器内部转换。`content` 是派生纯文本，供搜索、摘要、字数和文本导出使用。

通过 `blockDocument.create/normalize/text` 创建、校验和提取正文，通过 `notebook.edit({ document })` 或带 revision 的 `notebook_update` 修改。不要直接改 notes.json。旧版同结构块页面无需迁移；停用格式时保留原数据，恢复格式后可继续编辑。不提供其他格式原地转换或 JSON 导入界面。

文档最多 1000 块、12 层子块、200000 个正文字符（包含块分隔开销），序列化大小最多 1750000 字节。格式与树操作测试见 `test/block-page.test.js`，真实编辑器快捷键、嵌套和粘贴测试见 `test/block-page-interaction.test.js`。
