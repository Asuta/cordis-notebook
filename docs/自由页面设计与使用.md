# 自由页面：文档、容器与画布

本实现参考 Windows Microsoft 365 OneNote 的自由页面交互，以及微软公开的 [MS-ONE 对象模型](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-one/73d22548-a613-4350-8c23-07d15576be50)。它不读写 `.one` 二进制，也不宣称与 OneNote 文件兼容。MS-ONE 的 Page / Outline / OutlineElement / RichText 关系用于指导自己的持久化结构；Tiptap / ProseMirror 只负责编辑。

## 已实现

- 向右、向下延伸的纸张，滚动条浏览；单击空白位置或「新建容器」开始输入。
- 容器顶部拖动、右上角调整宽度，高度随内容变化；靠近边缘自动滚动。Ctrl 点击操作柄多选，选择工具框选，Shift 拖到另一容器合并。当前段落可拆为另一容器。
- 正文与六级标题、字体和字号、粗体/斜体/下划线/删除线、颜色/高亮、上下标、链接、引用、代码、编号/项目符号、对齐和缩进；复制和应用文字格式。
- 待办、重要、问题、定义、灵感标记；点击待办框切换状态。缩进段落可随上级折叠，支持上下移动段落。
- 3×3 表格及增删行列、合并/拆分单元格、列宽调整。通过文件选择、粘贴或拖放插入本地图片，支持图片尺寸调整。
- 手形工具、中键以及非文字输入时按住空格平移；25%–300% 缩放，Ctrl+滚轮围绕指针缩放；纸张颜色、横线、方格、点阵；向下拖动「插入空间」推开后续容器。
- 文字、格式、布局、纸张设置共用每篇笔记的撤销历史（最多 80 步），自动保存和浏览器草稿恢复；刷新后历史清空，滚动位置和缩放在本标签页保留。
- 输入区域禁用浏览器拼写检查。普通笔记、Markdown 笔记仍使用原编辑器。

「快捷键」按钮提供完整说明。主要组合：Ctrl+B/I/U、Ctrl+K、Ctrl+1/2/3、Ctrl+Z/Y、Tab/Shift+Tab、Alt+Shift+方向键。Esc 从文字编辑转为选择容器；此时 Ctrl+A/C/X/V 操作容器，Delete 删除所选容器。光标在正文内时仍按文字语义操作。

## 插件边界

| 插件 | 职责与依赖 |
| --- | --- |
| `rich-text` | 前后端提供 `richText`：版本校验、规范化、纯文本提取；浏览器额外提供消费上下文所有的编辑器挂载。引擎打包在插件自身目录。 |
| `note-assets` | 后端依赖 `http/storage`，提供图片上传与读取；浏览器提供 `noteAssets.upload(file)`。 |
| `format-freeform` | 依赖 `noteFormats/richText`，负责页面版本、容器坐标和文档校验、派生正文。 |
| `free-page-editor` | 依赖 `ui/notebook/editorHost/noteFormats/richText/noteAssets`，负责工具栏、容器交互、视口和统一历史。 |

插件互相调用服务，不跨目录导入实现。停用提供者受到现有依赖保护；编辑器、事件、观察器和 DOM 随消费上下文清理。

## 存储与旧数据

页面 `version: 2`；`blocks` 保持容器的 `id/x/y/width`，新增 `outline`；`page` 保存颜色和格线。缩放和滚动属于视口，不改变文档坐标。

```json
{
  "version": 2,
  "page": { "color": "#ffffff", "rule": "none" },
  "blocks": [{
    "id": "container-1", "x": 40, "y": 40, "width": 420,
    "text": "一段文字",
    "outline": { "version": 1, "elements": [{
      "id": "paragraph-1", "kind": "paragraph", "indent": 0,
      "align": "left", "tag": null, "checked": false, "collapsed": false,
      "runs": [{ "text": "一段文字", "format": { "bold": true, "size": 12 } }]
    }] }
  }]
}
```

旧版只有 `text` 的容器可直接打开，显示时转换为段落；实际编辑时写入 `outline`。不在启动读取时批量改写用户文件。`text` 和页面 `content` 从文档重新计算，继续供搜索、字数、摘要和 TXT 导出使用。

图片保存在笔记 JSON 同目录下的 `note-assets/`，以内容哈希去重，单张限 1 MiB，支持 PNG/JPEG/GIF/WebP。文档只保存资源地址，拒绝远程图片地址和不安全链接。删除内容不会自动清除图片，以免破坏撤销和其他笔记引用。**备份需同时复制笔记 JSON 与资源目录**；单篇 JSON 导出保留完整文档结构，但不嵌入图片字节，TXT 仅导出文本。

当前限制：最多 1000 个容器、页面纯文本最多 200000 个 JS 字符；每个富文本文档最多 10000 个节点/文字片段、16 层；表格最多 100 行和 20 列；页面容器的序列化数据最多 1750000 字节，为 HTTP 请求留出空间。暂未实现手写墨迹、OCR、音视频、数学公式、协同编辑、`.one` 导入导出或格式原地转换。浏览器字体取决于本机安装，菜单和默认样式并非微软官方编辑器。
