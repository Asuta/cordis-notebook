# 插件能力索引

由 `pnpm docs:capabilities` 从提供者清单生成。这里只描述能力契约；实时提供者状态请查询 `/api/capabilities`，前端状态需由页面核对。

| 应用 | 提供者 | 能力 | 说明 | 契约 |
| --- | --- | --- | --- | --- |
| notebook | note-formats | client:noteFormats | 页面笔记格式注册、正文提取和只读快照 | [types/client.d.ts](../applications/notebook/plugins/note-formats/types/client.d.ts)、[types/data.d.ts](../applications/notebook/plugins/note-formats/types/data.d.ts) |
| notebook | note-formats | server:noteFormats | 服务端独立校验笔记格式与派生正文 | [types/server.d.ts](../applications/notebook/plugins/note-formats/types/server.d.ts)、[types/data.d.ts](../applications/notebook/plugins/note-formats/types/data.d.ts) |
| notebook | notes | server:notes | 持久化笔记的增删改查与版本校验 | [types/server.d.ts](../applications/notebook/plugins/notes/types/server.d.ts)、[types/data.d.ts](../applications/notebook/plugins/notes/types/data.d.ts) |
| notebook | layout | client:shell | 笔记应用的布局插槽 | [types/client.d.ts](../applications/notebook/plugins/layout/types/client.d.ts) |
| notebook | notebook | client:notebook | 当前页面的笔记、草稿、保存与筛选服务 | [types/client.d.ts](../applications/notebook/plugins/notebook/types/client.d.ts) |
| notebook | editor-host | client:editorHost | 按格式的 editor 标识注册编辑区与可选标题位置 | [types/client.d.ts](../applications/notebook/plugins/editor-host/types/client.d.ts) |
| studio | canvas | client:canvasSession | 当前画板、编辑历史与页面交互会话 | [types/client.d.ts](../applications/studio/plugins/canvas/types/client.d.ts)、[types/data.d.ts](../applications/studio/plugins/canvas/types/data.d.ts) |
| studio | canvas | server:canvasDocuments | 画布文档与可扩展卡片类型的持久化服务 | [types/server.d.ts](../applications/studio/plugins/canvas/types/server.d.ts)、[types/data.d.ts](../applications/studio/plugins/canvas/types/data.d.ts) |
| studio | canvas-ui | client:canvasUI | 画布菜单、卡片视图和扩展区域 | [types/client.d.ts](../applications/studio/plugins/canvas-ui/types/client.d.ts) |
